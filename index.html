Las 5 unidades del programa

Cada unidad combina teoría, práctica con herramientas reales y entregables evaluables.

U1

Identificación y preservación

Hashes criptográficos (MD5/SHA-256), efecto avalancha, metadatos EXIF/GPS y verificación de cadena de custodia.

exiftoolmd5sumsha256sumxxd
U2

Adquisición

Adquisición bit-a-bit con dc3dd, captura de RAM con AVML y documentación FPJ-8 (cadena de custodia).

dc3ddavmlddlsblk
U3

Análisis de disco

Sleuth Kit para inodos y journaling, file carving con photorec, análisis de registro Windows (RegRipper).

sleuthkitflsistatphotorec
U4

Memoria y redes

Análisis de RAM con Volatility, captura y filtrado de paquetes con TShark, lectura de .pcap.

volatilitytsharkwireshark
U5

Documentación y dictamen

Elaboración de dictámenes periciales, cadena de custodia formal y exportación de evidencia procesable.

FPJ-8dictamenreportes
